三、评论区

1. 在 GitHub 开启 Discussions

Giscus 把评论保存到 GitHub Discussions，不需要单独维护数据库。开始前需要完成以下操作：

  1. 评论所用的 GitHub 仓库必须是公开仓库；
  2. 进入仓库的 Settings → General → Features，勾选 Discussions；
  3. 打开 giscus.app 中文配置页；
  4. 按页面提示安装 Giscus App，并授权它访问评论仓库；
  5. 在“仓库”输入框填写 用户名/仓库名，例如 Lamb-fish/Lamb-fish.github.io。

2. 在 Giscus 页面生成参数

仓库检查通过后，继续选择：

  • 页面与 Discussion 的映射使用 pathname，每个页面路径对应一个讨论；
  • Discussion 分类选择 Announcements；
  • 开启反应，将评论框放在评论下方；
  • 语言选择简体中文，主题分别选择浅色和深色。

页面底部会生成一段 <script>。不需要把整段脚本复制到 Markdown，只需从中找到 data-repo-id 和 data-category-id，再填入 _config.butterfly.yml：

repo_id 和 category_id 不是仓库名与分类名，不要手动猜测，直接复制 Giscus 页面生成的值。
