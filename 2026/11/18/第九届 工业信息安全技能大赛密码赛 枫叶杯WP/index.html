（3）该公司的一个内部工作人员Eve的银行卡号为：6228 4800 1030 1477 914，卡号数据用UTF-8格式存储（见代码 BYTE CardNumber * = “6228 4800 1030 1477 914”;）
其转换为16进制是：0x3632323820343830302031303330203134373720393134。如果Eve获取了如下加密数据信息：求取Bob的卡号是?

加密原理：

OFB模式将SM4分组密码转换为同步密钥流加密

K为SM4密钥，IV为128位全零初始向量，$E_k$为SM4分组加密函数，$P_i$为第i个明文分组

密钥流生成：

$$S_1=E_k(IV),\quad S_2=E_k(S_1),\quad S_3=E_k(S_2)$$

明文与密钥流异或：$C_i=P_i \oplus S_i$

解密为：$P_i=C_i \oplus S_i$

解题思路

OFB在同一密钥下重复使用固定的IV，会生成相同的密钥流：

$$C_1=P_1 \oplus S,\quad C_2=P_2 \oplus S$$

则$C_1 \oplus C_2 =P_1 \oplus P_2$

思路

每次签名都用相同进程 ID 初始化伪随机生成器，导致后续rand()产生相同序列，从而生成相同的k

SM2 签名公式：

$$r=(e+x_1) \pmod n,\quad s=\frac{k-rd_A}{1+d_A} \pmod n$$

$$\Rightarrow k=s+d_A(s+r) \pmod n$$

又两次签名的k相同：

$$s_1+d_A(s_1+r_1)=s_2+d_A(s_2+r_2) \pmod n$$

$$\Rightarrow d_A=(s_2-s_1)(s_1+r_1-s_2-r_2)^{-1}\pmod n$$

思路

用明文P和密文C可得到密钥流：

$S_i=P_i \oplus C_i=K_{i+64}$

由线性递推关系，通过GF(2)线性方程组恢复初始64字节

$K_{i+64}=K_i\oplus K_{i+2} \oplus K_{i+5} \oplus K_{i+6}$

记 $A=\mathrm{SHA512}(p)$，$B=\mathrm{SHA256}^{20001}(p)$

初始密钥满足：$K_i=A_i \oplus B_{i \bmod 32}$

则：$K_i \oplus K_{i+32}=A_i \oplus A_{i+32}$

枚举长度为 4～8 位的数字串，只需计算 SHA-512 并匹配上述关系
